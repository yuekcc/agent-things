# 技能

本目录包含用于各种开发任务的 AI 代理技能。

## 可用技能

| 技能 | 描述 |
|------|------|
| [improve-codebase-architecture](improve-codebase-architecture/) | 在领域语言的指导下，发现代码库中需要深入改进的地方。当用户想要改善架构、寻找重构机会、整合紧密耦合的模块，或使代码库更易于测试和 AI 导航时使用。 |
| [tdd](tdd/) | 测试驱动开发，包含红-绿-重构循环。当用户想要使用 TDD 构建功能或修复 bug、提到"红-绿-重构"、想要集成测试，或请求测试先行开发时使用。 |
| [to-prd](to-prd/) | 将当前对话上下文转换为 PRD 并作为 GitHub issue 提交。当用户想要从当前上下文创建 PRD 时使用。 |
| [write-a-skill](write-a-skill/) | 创建具有适当结构、渐进式披露和捆绑资源的新代理技能。当用户想要创建、编写或构建新技能时使用。 |
